# 비-MILP 비교 입력 데이터 (폐기됨)

트럭 비교 입력은 이제 결과 패키지 안의 **주차별 폴더**에 있다.

    reference_data/JULY_W1W2_RESULTS/
      mode_comparison/outputs/<weekId>/TRUCK_COMPARISON_BY_RECOMMENDATION.csv

이 폴더에 있던 `TRUCK_COMPARISON_BY_RECOMMENDATION.csv` 는 2026-08 스냅샷
기준이라 2025-07 결과와 REC ID 가 겹치면서 내용이 전혀 달랐다. 주차 밖에서
한 파일을 공유하면 엉뚱한 건의 트럭 비용이 조용히 붙으므로 제거했다.
